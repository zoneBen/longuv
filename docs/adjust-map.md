# Modbus TCP 调整服务（0x8000 影子寄存器）

> 调整服务使用标准 Modbus TCP（MBAP），默认监听 `0.0.0.0:15020`（可配）。
> 它只暴露 **0x8000 影子区**，与 RTU 原生地址（0x0000–0x05FF 宽松区）完全分离；一份寄存器状态由两个服务共享。

## 1. 连接与 unit

- 每个设备有一个唯一的 `tcp_unit_id`（1..247，缺省自动分配）。
- 请求 unit 为 `0` 或 `0xFF` 时使用 `server.modbus_tcp.default_unit`（默认 1）。
- 未知 unit 返回异常 **0x0B**。
- 支持多客户端并发与流水线请求；每连接空闲超时可配。

## 2. 保持寄存器（FC03 读 / FC06、FC10 写）

| 地址 | 数量 | 内容 | 权限 |
|------|------|------|------|
| 0x8000–0x8005 | 6 | 型号 / 主绑定地址 / 波特率码 / U 位长度 / 软件 / 固件 | 只读 |
| 0x8006–0x800F | 10 | ESN（20 ASCII，大端） | 读写 |
| 0x8010–0x80B7 | 168 | U 位标签，U(i)=0x8010+(i-1)*4，4 字=8 字节 | 读写 |
| 0x80C0–0x80C2 | 3 | 上/中/下温湿度 raw；写入即冻结该区为手动 | 读写 |
| 0x80C3–0x80C5 | 3 | 连接 / 通讯正常 / 过流 | 读写 |
| 0x80D0–0x80F9 | 42 | U1–U42 LED 值 | 读写 |
| 0x8100–0x8102 | 3 | 在位位图（42 位，LSB 先行） | 读写 |
| 0x8110–0x8112 | 3 | 变化位图 | 读写 |
| 0x8120 | 1 | 命令：1=清变化位，2=全部恢复自动 | 写 |
| 0x8121 | 1 | 手动覆盖掩码（bit0 上 / bit1 中 / bit2 下） | 只读 |
| 其余 | — | 读 0；写异常 02 | — |

- 写标签/在位/总线/LED 会立即可被 RTU 采集读到；反之亦然。
- 写在位位图为 1 时，若标签为全 0，会自动生成默认标签（`E2…U`）；清位会清空标签。
- 温湿度 raw 的编码与 RTU 相同：高字节温度、低字节湿度；写入后该区进入手动模式，直到命令 0x8120=2 或页面“恢复自动”。

## 3. 输入寄存器（FC04 只读镜像）

0x8000 起的地址与保持寄存器表**同地址镜像**，只读，便于只支持 FC04 的主站做监视。
FC04 写请求不被支持（保持寄存器写请用 FC06/FC10）。

## 4. 线圈（FC01 读 / FC05、FC0F 写）

| 地址 | 内容 |
|------|------|
| 0x8000–0x8029 | U1–U42 在位（可写；置位生成默认标签，清位清标签） |
| 0x8030–0x8059 | U1–U42 变化位（写 1 触发，写 0 清除） |
| 0x8060–0x8062 | 上/中/下手动开关：写 1 冻结当前值，写 0 恢复自动 |
| 0x8070 | 清变化位命令（写 1 生效） |
| 其余 | 读 0；写异常 02 |

## 5. 离散输入（FC02 只读）

| 地址 | 内容 |
|------|------|
| 0x8000–0x8029 | 在位 |
| 0x8030–0x8059 | 变化 |
| 0x8060–0x8062 | 当前处于手动覆盖的区 |
| 0x8063–0x8065 | 连接 / 通讯正常 / 过流 |

## 6. 常用示例

`mbpoll` 默认地址是 1-based，**务必加 `-0`**：

```bash
# 设备信息（FC03 保持寄存器，0x8000=32768）
mbpoll -m tcp -p 15020 -a 1 -0 -r 32768 -c 6 -t 3 127.0.0.1

# 温湿度影子区（0x80C0=32832）
mbpoll -m tcp -p 15020 -a 1 -0 -r 32832 -c 3 -t 3 127.0.0.1

# 读 U1 标签（0x8010=32784）
mbpoll -m tcp -p 15020 -a 1 -0 -r 32784 -c 4 -t 3 127.0.0.1

# 写 LED U1 = 0x00A0（0x80D0=32848）
mbpoll -m tcp -p 15020 -a 1 -0 -r 32848 -c 1 -t 3 -w 0x00A0 127.0.0.1

# 清除全部变化位（命令 0x8120=33056 写 1）
mbpoll -m tcp -p 15020 -a 1 -0 -r 33056 -c 1 -t 3 -w 1 127.0.0.1
```

pymodbus 示例：

```python
from pymodbus.client import ModbusTcpClient
c = ModbusTcpClient("127.0.0.1", port=15020)
print(c.read_holding_registers(address=0x8000, count=6, slave=1).registers)
print(c.read_input_registers(address=0x80C0, count=3, slave=1).registers)
c.write_register(address=0x80D0, value=0x00A0, slave=1)
```

## 7. 与 RTU 的关系

- 同一 `Device` 对象：RTU 的 FC03/04/06 与 TCP 影子区读写的是同一份寄存器。
- RTU 原生 `0x0100` 是 LED，FC04 `0x0100` 是温湿度；TCP 影子区用 0x80xx 一一映射，避免混淆。
- 设备信息里的“地址”是主绑定地址；RTU 读 `0x0001` 时返回**当前端口绑定地址**。
- TCP 写入会触发 state.json 防抖保存；重启后保留（自动温湿度计算值除外）。
